# UTILIA

**Pequeñas herramientas. Grandes soluciones.**

UTILIA es una aplicación de utilidades cotidianas, diseñada para resolver tareas pequeñas de forma rápida y clara.

## Stack
- Flutter
- Dart
- Material 3
- Android como primera plataforma
- GitHub Actions para CI

## MVP 0.1
- Inicio y categorías
- Búsqueda visual
- Dinero
- Coche
- Calculadora de IVA (4%, 10%, 21%)
- Base preparada para favoritos e historial

## Hoja de ruta
1. Completar las herramientas MVP prioritarias.
2. Persistencia local de favoritos e historial.
3. Tema claro/oscuro.
4. Tests unitarios de todas las fórmulas.
5. Accesibilidad y localización.
6. CI y builds Android.
7. Preparación para Google Play.

## Principios
- Sin cuentas en la primera versión.
- Sin backend mientras no sea necesario.
- Privacidad por defecto.
- Fórmulas deterministas y testeables.
- UX rápida: el resultado debe estar a pocos toques.
