# Política de privacidad de UTILIA

**Última actualización: 7 de septiembre de 2026**

UTILIA es una aplicación de herramientas y calculadoras para Android desarrollada como una aplicación local y orientada a la privacidad.

## 1. Datos que recoge UTILIA

UTILIA no requiere una cuenta y no recopila ni envía a servidores propios datos personales, datos de salud, ubicación, contactos, fotografías ni identificadores personales.

Las preferencias de la aplicación, como favoritos, historial de cálculos, idioma y modo oscuro, se almacenan localmente en el dispositivo mediante almacenamiento local de la aplicación.

## 2. Compartir resultados

UTILIA permite utilizar la función de compartir del sistema Android para enviar voluntariamente un resultado o cálculo a otra aplicación elegida por el usuario. En ese caso, el contenido se entrega directamente a la aplicación seleccionada mediante los mecanismos de Android. UTILIA no controla ni recibe posteriormente el contenido gestionado por esa aplicación.

## 3. Servicios de terceros

UTILIA utiliza bibliotecas de software de terceros necesarias para ejecutar la aplicación, incluyendo componentes de Flutter, almacenamiento local y la función de compartir del sistema. UTILIA no utiliza actualmente publicidad, analítica, seguimiento publicitario, cuentas de usuario ni servicios propios de recopilación de datos.

## 4. Conservación y eliminación

Los datos almacenados localmente por UTILIA permanecen en el dispositivo hasta que el usuario los elimina desde las funciones disponibles de la aplicación, borra el historial, restablece los datos de la aplicación o desinstala UTILIA.

## 5. Seguridad

UTILIA está diseñada para realizar sus cálculos localmente y minimizar la transmisión de información. No existe una cuenta de usuario de UTILIA ni un servidor propio que almacene el historial o los favoritos.

## 6. Menores

UTILIA no solicita conscientemente datos personales de menores ni requiere el registro de usuarios.

## 7. Cambios en esta política

Esta política puede actualizarse cuando cambien las funciones, dependencias o prácticas de privacidad de UTILIA. La fecha de actualización se indicará al principio de esta página.
